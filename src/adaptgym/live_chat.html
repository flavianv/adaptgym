EXTRACTION METRICS

Live chat shows operational metrics because it has no labeled ground truth. Replay also shows per-turn value precision and recall against the saved reference: capitalization is ignored and arrays are scored as value sets. Reference labels flagged by the audit remain marked for review.

About this session

Live conversation and live extraction use GPT-6 Luna. Play pre-extracted offers saved Luna, Qwen 4B zero-shot and Qwen 4B fine-tuned outputs, with synchronized model comparison. Saved experiment traces use the same full extraction prompt; Luna uses the OpenAI Responses API while Qwen uses the frozen local-serving configuration. Conversations stay in server memory for up to one hour. Start a new chat to reset the profile.

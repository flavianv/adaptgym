Learning to adapt
CONTEXT → TARGET


Train the recommendation agent to update its understanding as the shopper adds, changes, or withdraws requirements.






Each turn shows the private scenario instruction, the generated training context, and its expected intent label. The context uses the model’s previous valid prediction and the observed conversation; reference states appear only as targets and in scoring. Invalid outputs do not replace the last valid model state. Private instructions explain how labels were constructed; they are excluded from model inputs. All turns are shown in one panel so you can follow what changes. Targets come from the scenario; the separate verifier checks their support in the generated dialogue. Model predictions and audit details are optional diagnostics, not training targets.

LIVE BACKEND PROMPTS
These are the actual instruction prompts served by the backend. Each verification call checks either the planned label or the model's extracted intent, including its search request. The judgment is whether the whole intent is supported—not whether its wording matches a reference string.
Conversation generator
Receives the persona, current private instruction, and latest assistant message. Generates one shopper message; assistant replies are programmed.
Intent verifier / judge
Receives schema, catalog, visible conversation, and candidate intent. No private scenario instructions or future messages. Returns claim checks, task/selection observations, missing intent, and a search-request verdict.
